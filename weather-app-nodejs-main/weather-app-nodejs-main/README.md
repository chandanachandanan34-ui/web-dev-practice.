# weather-app-nodejs
# 🌦 Weather App

## 📌 Description
This is a simple weather application that allows users to search for any city and get real-time weather data.

## 🚀 Features
- Search weather by city
- Displays temperature, humidity, wind
- Clean UI design

## 🛠 Tech Stack
- Node.js
- Express.js
- Axios
- EJS
- CSS

## ▶️ How to Run
1. Clone the repo
2. Run: npm install
3. Run: node index.js
4. Open: http://localhost:3000
